# Governance Records

This directory preserves public-safe provenance for material ARRP governance
decisions. The [Governance Change Log](governance-change-log.md) is the
reader-facing history; the project workflow registry supplies its stable
identities and structured evidence.

These records do not replace the current governing authority, Git history,
issue audit history, GitHub workflow record, or the frozen historical
[Change Audit Log](../audits/change-audit-log.md). They contain no restricted
evidence or owner-local operational detail.
