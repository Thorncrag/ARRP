# Reusable Standards

This directory contains the rules, schemas, and templates that apply broadly
across the project and are intended to remain useful when ARRP is adapted as a
future project template.

Standards are organized by the thing they govern:

- [`content/`](content/) — content identity, architecture, maturity, remedies,
  navigation, and content templates;
- [`sources/`](sources/) — claims, citations, evidence records, source
  adjudication, monitoring, and source templates;
- [`audits/`](audits/) — audit methods, levels, verification, change control,
  legal review, and reusable scoring discipline;
- [`publication/`](publication/) — edition, print, export, and release rules;
- [`interfaces/`](interfaces/) — interface, progress-view, public-input, and
  [work-tracking](interfaces/work-tracking.md) rules; and
- [`automation/`](automation/) — execution, context, delegation, provenance,
  validation, and handoff rules.

ARRP-specific configuration and named procedures belong in
[`../project/`](../project/). State and history belong in
[`../records/`](../records/). Actual issue, legislation, topic, source, and
research content remains outside `framework/`.
