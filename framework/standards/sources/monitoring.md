# Content and Project Monitoring Standard

## Authority and Dependencies

This file governs monitoring as a reusable content and source-review method.
Source-level monitoring metadata and evidence placement are governed by
[`source-records.md`](source-records.md). Each project defines its exact hosted
work-item fields, labels, views, deterministic watchers, and interface
projection in the project-configuration layer.

## Load When

Load this file when applying, reviewing, or removing monitoring; conducting a
project-wide monitoring pass; responding to a detected external development;
or deciding whether an external matter is merely being watched, affirmatively
deferred, blocked by an indispensable prerequisite, or awaiting a human
decision.

## Accountable-record monitoring

Attach monitoring to the existing accountable content or work record when an
external development is materially relevant and useful work may continue
regardless of its outcome. Preserve the record's ordinary maturity and
workflow state; do not create a second substantive record merely to represent
monitoring.

The accountable record must identify:

1. the watched matter;
2. why it is materially relevant;
3. the event or condition that triggers reassessment;
4. the checking method and responsible owner; and
5. the latest dated result.

Monitoring is independent of workflow state. If useful work may continue,
retain the ordinary state and the separate monitoring designation. If intended
work cannot proceed without a concrete indispensable prerequisite, classify
the work as blocked. If work could proceed but the project has affirmatively
chosen not to continue, classify it as deferred. A missing human-reserved
choice is a human decision, not monitoring or blockage.

## Project-wide monitoring pass

A project-wide monitoring pass is a non-scoring review of every active record
with a monitoring designation. It does not alter a score, maturity, workflow
state, or audit-run count merely because the watched matter remains open.

For each record, review all associated sources and actively search for material
new developments not yet captured by the catalog. Refresh changing source
posture, record a concise dated result on the accountable record, update source
and reader-facing evidence placement as needed, and remove monitoring only
when no continuing review need remains. A material result triggers the
ordinary change-control and remedy-fit review before the affected content is
treated as current.

Deterministic watchers may assist but do not replace the pass. Their
observations are routing signals, not conclusions about significance,
content-fit, disposition, or development. Routine monitoring is not itself a
human action item; only a detected development, exception, or decision that
actually requires human attention belongs there.

Source volume may establish recurrence, breadth, or persistence, but a raw
record count is not itself evidence of legality, severity, motive, or
institutional failure. Distinguish verified episodes, primary records,
official findings, final adjudications, open matters, corroborating sources,
and unverified leads. When volume is material, state both episode and
source-record counts so multiple reports about one event are not mistaken for
separate manifestations.
