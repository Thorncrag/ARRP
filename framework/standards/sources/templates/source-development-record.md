# Source-Development Record Template

Use this template for an internal shell that routes a canonical content
identifier to its source-development record before a substantive public page is
ready. Replace the generic metadata and path with the project's configured
identifiers, location, and publication disposition.

```markdown
---
record_id: RECORD-000
collection_id: COLLECTION-00
title: "Content title"
record_type: source-development
# Add the project-configured publication metadata here.
---

# RECORD-000 — Content title

> **Source-development record only.** This internal shell records the current scope and routes supporting material for later review. It does not establish a completed institutional diagnosis; admission as a final proposal where the question remains unresolved; any remedy or proposed legislation; a proposal-quality score; or an audit status.

## Scope Under Review

State the current issue boundary in one or two neutral sentences. Do not add manifestations, findings, legal conclusions, remedies, source summaries, or reader-facing analysis.

## Source-Development Record

- Link the completed shell to the project-configured internal source-development record.

The linked internal record owns the research workflow. It is not reader-facing evidence and does not itself establish any project conclusion.

## Next Development Step

State the next verification, boundary, comparator, or remedy-selection task without implying that the work has been completed.
```
